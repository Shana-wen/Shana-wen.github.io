# 基于Zephyr的嵌入式系统工程目录结构

## 项目概述

这是一个基于 **Zephyr** 的嵌入式系统项目。

## SDK主要目录结构

```
├── arch/
│   └── mips/
│       └── soc/
│           └── actions/
│               └── woodpecker/ # Actions ATS285x系列soc支持目录
├── boards/
│   └── mips/
│       └── ats2853_dvb/        # ATS2853 DVB 版型配置和代码
├── drivers/                    # 各个驱动程序
├── ext/
│   └── actions/                # Actions应用框架
├── include/                    # Zephyr原生include
├── kernel/                     # 内核代码
├── samples/
│   └── bt_box/                 # 蓝牙音箱示例应用
├── scripts/                    # 构建和工具脚本
│   └── support/
│       └── actions/            # 打包和量产脚本
├── subsys/                     # 文件系统等硬件无关子系统
```
## 一级目录功能说明

| 目录/文件    | 功能描述                             |
| ------------ | ------------------------------------ |
| **arch/**    | 处理器架构相关代码（MIPS架构的文件） |
| **boards/**  | 开发板配置和支持代码                 |
| **drivers/** | 硬件驱动程序（GPIO、I2C、SPI等）     |
| **dts/**     | 设备树文件配置                       |
| **ext/**     | 外部依赖和扩展库                     |
| **include/** | 全局头文件（API定义、接口声明）      |
| **kernel/**  | Zephyr内核核心实现                   |
| **lib/**     | 通用库和工具函数                     |
| **misc/**    | 杂项工具和功能                       |
| **samples/** | 应用示例                             |
| **scripts/** | 构建和工具脚本                       |
| **subsys/**  | 子系统实现（蓝牙、网络等）           |
| **tests/**   | 单元测试和集成测试                   |

## 目录结构详细说明

### 📁 **arch/** 架构层
```
arch/
├── common/             # 通用架构代码
└── mips/               # MIPS处理器相关
```

### 📁 **boards/** 开发板支持
```
boards/
└── mips/
    └── ats2853_dvb/    # ATS2853 DVB 版型相关代码和配置
                        # 包含开发板的初始化、外设配置等
```

### 📁 **drivers/** 驱动层
包含40+个子目录，主要驱动类型：
- **通信**：uart, i2c, spi, usb, bluetooth
- **音频**：audio, i2s, dsp
- **存储**：flash, mmc, nvram
- **控制**：gpio, pinmux, pwm, timer
- **电源**：power, dvfs, watchdog
- **传感**：sensor, adc, counter

### 📁 **ext/** 扩展库
```
ext/
├── actions/            # Actions公司特定实现
├── debug/              # 调试工具
├── fs/                 # 文件系统
├── hal/                # 硬件抽象层
└── lib/                # 第三方库
```

### 📁 **include/** 头文件库
包含所有公共接口定义：
- 核心API：device.h, kernel.h, atomic.h
- 驱动接口：gpio.h, i2c.h, uart.h, pwm.h等
- 音频系统：audio.h, audio_in.h, audio_out.h
- 配置管理：config/
- 编译工具链：toolchain/

### 📁 **kernel/** 内核核心
包含OS内核的实现：
- 进程/线程管理
- 中断处理
- 时钟和定时器
- 内存管理
- 设备管理

### 📁 **samples/** 应用
```
samples/
└──  bt_box/            # 蓝牙音箱示例应用
```

### 📁 **scripts/** 构建和工具脚本
```
scripts/
└── support/
    └── actions/        # 打包和量产脚本目录
                        # 包含编译、打包、烧录等自动化脚本
```

### 📁 **subsys/** 子系统
中间件层实现：
- 蓝牙管理（bluetooth）
- 网络协议栈
- 文件系统
- 日志和追踪

## 构建配置文件说明

| 文件                | 作用                   |
| ------------------- | ---------------------- |
| **Kconfig**         | Menuconfig配置选项定义 |
| **Kbuild**          | 编译规则定义           |
| **Makefile**        | 顶级编译入口           |
| **build.sh**        | 构建脚本               |
| **clean_zs285a.sh** | 清理编译产物           |
| **genpatch.sh**     | 补丁生成工具           |

## 层级架构关系

```
┌─────────────────────────────────┐
│   应用层 (samples/bt_box)       │
├─────────────────────────────────┤
│   中间件层 (subsys)             │ 音频管理、蓝牙管理等
├─────────────────────────────────┤
│   驱动层 (drivers)              │ I2C、SPI、GPIO等硬件驱动
├─────────────────────────────────┤
│   系统库 (lib, ext)             │ 工具函数、算法库
├─────────────────────────────────┤
│   内核层 (kernel)               │ 线程、中断、内存管理
├─────────────────────────────────┤
│   硬件抽象层 (hal)              │ 寄存器/硬件操作封装
├─────────────────────────────────┤
│   架构层 (arch)                 │ MIPS处理器特定代码
├─────────────────────────────────┤
│   硬件 (ZS285A芯片)             │
└─────────────────────────────────┘
```
