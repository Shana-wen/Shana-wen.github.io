# WiFi配置
## 连接WiFi
```bash
# 查看网络设备
sudo nmcli dev

# 开启wifi
sudo nmcli r wifi on

# 扫描wifi
sudo nmcli dev wifi

# 连接wifi
sudo nmcli dev wifi connect "wifi名" password "密码"
```

# 接入点模式 (Access Point)
```bash
# 清理冲突进程
sudo killall hostapd udhcpd wpa_supplicant udhcpc

# 重启网卡
sudo ifconfig wlp2s0 down
sudo ifconfig wlp2s0 up

# 设置静态 IP
sudo ifconfig wlp2s0 192.168.43.1

# 使能DHCP，自动分配IP服务
sudo udhcpd /etc/udhcpd.conf

#开启WiFi
sudo hostapd -B /etc/hostapd.conf 
```
